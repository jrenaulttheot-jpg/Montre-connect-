Console BLE K56 Pro

Se connecte directement à ta montre en Bluetooth Low Energy, sans passer par l'app Da Fit. Explore les services GATT, lit la batterie et les infos device, envoie des commandes brutes du protocole Moyoung.

Web Bluetooth indisponible sur iOS. Apple bloque cette API dans tous les navigateurs iPhone (Safari, Chrome, Edge — même moteur WebKit imposé). Pour utiliser cette console sur iPhone, installe Bluefy (gratuit, App Store), c'est un navigateur qui débloque le Bluetooth pour le web, puis ouvre cette page dedans.
